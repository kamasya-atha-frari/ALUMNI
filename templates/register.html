Security & Authorization Architecture

  • Continue with Google (OAuth 2.0): Verifies Google identity with signed CSRF state and verified-email checks, automatically linking or creating your account and issuing a Bearer token.
  • Server-Side Anti-Bot CAPTCHA: Standard form registration requires a valid, single-use, short-TTL SVG/Math challenge verified before database writes.
  • Salted Password Hashing: Local passwords are hashed with PHP password_hash() prior to MySQL storage.
  • Unified Bearer Token Flow: Both registration flows issue an HS256 JWT token for Authorization: Bearer requests and RBAC enforcement.
